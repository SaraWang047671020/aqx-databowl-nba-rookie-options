凍結第四輪補查資料，單次傷病候選門檻 >27 天；0 表示未找到已支持事件，不代表健康。這些檔案保留研究過程，不作網站或主分析輸入。

- `manual_review_overrides.csv`：第四輪人工判讀與來源連結。所列官方頁面／PDF以工具返回的搜尋收錄內容核對，未宣稱本輪全部下載原檔。Hutchison 的 Doubtful 並非正式 Out，仍須搭配出賽紀錄解讀。
- `paired_comparison.csv`：固定 0.8 與 0 的完整網成對比較。306 人中 5 人改善、2 人惡化；後期 140 人仅 Hunter 改善，移除他或 2020 梯次後增益歸零。
- `changed_player_audit.csv`：7 名續約／放棄判定改變者與證據疑點。並非已認證完整傷病史。
- `../no_injury/supplementary_grid.csv`：報告附錄的 36 組情境，使用補查最低次數，非最終採用參數。

精確成對檢查視球員為獨立觀測，未建模同梯關聯，且後期資料已被反覆檢視；僅作描述診斷，不是新盲測或因果效果。不能宣稱 Hunter 純屬偶然，也不能稱 0.8 是穩定最佳權重。
